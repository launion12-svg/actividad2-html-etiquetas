2. Párrafos y texto

El elemento párrafo (<p>) es la unidad básica de texto. Se pueden combinar con etiquetas de énfasis:

Texto en negrita con <strong> (importancia semántica), texto en cursiva con <em> (énfasis), texto resaltado con <mark>, texto tachado con <del> y texto pequeño con <small>.

También es posible incluir HTML con el elemento <abbr> para abreviaturas accesibles.

"El HTML es el lenguaje de marcado estándar para crear páginas web."

3. Listas

Lista no ordenada (<ul>)

  • header – cabecera del documento
  • nav – navegación principal
  • main – contenido principal
  • section – sección temática
  • article – contenido autónomo
  • aside – contenido lateral
  • footer – pie de página

Lista ordenada (<ol>)

  1. Declarar el DOCTYPE: <!DOCTYPE html>
  2. Abrir la etiqueta <html lang="es">
  3. Añadir el bloque <head> con meta charset y title
  4. Escribir el contenido dentro de <body>
  5. Cerrar todas las etiquetas correctamente

8. Atributos globales y de accesibilidad

Los atributos globales pueden aplicarse a cualquier elemento HTML. Los atributos ARIA mejoran la accesibilidad para lectores de pantalla:

id Identificador único del elemento
class Clase CSS para estilos y JS
title Tooltip informativo al pasar el ratón
lang Idioma del contenido del elemento
data-* Atributos personalizados para JS/CSS
tabindex Orden de navegación por teclado
aria-label Etiqueta accesible para lectores de pantalla
aria-required Indica campo obligatorio en formularios
role Define el rol semántico del elemento
hidden Oculta el elemento visual y semánticamente
loading Carga diferida de imágenes (lazy/eager)
autocomplete Autocompletado en campos de formulario
